# Cortex mascot

The mascot SVG is a color trace of the approved illustration. Its numbered paths are editable vectors; the source image is flat, so overlapping body parts are not reconstructed as complete independent layers. Redraw hidden areas before animating parts such as the hands or laptop separately. The light and dark files use the same mascot and colors.

The favicon isolates the mascot’s three-node graph, using the same teal and coral palette. Its light and dark files are identical.
